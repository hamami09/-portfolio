PROJECT 01 / DETAIL PROYEK
Dalam pengembangan

LACI-VIRTUAL / MyGalery Radio

Sistem pendukung siaran TikTok LIVE yang menghubungkan interaksi penonton, tampilan overlay browser, dan informasi musik dalam satu alur kerja.

PythonTikTokLiveOpenCVHTML / CSS / JavaScriptVLCCloudflare Tunnel
01 / LATAR BELAKANG

Masalah yang ingin diselesaikan.

Saat siaran langsung, informasi lagu dan interaksi penonton perlu ditampilkan dengan cepat tanpa mengganggu tampilan utama kamera. Proyek ini mengeksplorasi cara mengotomatiskan bagian tersebut.

02 / FITUR & RUANG LINGKUP

Yang dibangun.

  • Server overlay lokal yang menyajikan tampilan untuk sumber Browser di LIVE Studio.
  • Pembacaan event TikTok LIVE seperti penonton bergabung, komentar, hati, hadiah, dan berbagi.
  • Pengiriman event ke overlay untuk menampilkan pesan interaktif.
  • Integrasi informasi lagu yang sedang diputar untuk konsep MyGalery Radio.
  • Eksperimen visualizer audio dan elemen tampilan siaran.
03 / TEKNOLOGI

Tools & teknologi.

PythonTikTokLiveOpenCVHTML / CSS / JavaScriptVLCCloudflare Tunnel
04 / PROSES BELAJAR

Pengalaman teknis.

Membangun komunikasi antarproses, menghubungkan event real-time ke antarmuka web, dan menguji akses overlay dari aplikasi siaran.

Catatan status: Proyek masih dikembangkan. Fitur dan kestabilan integrasi terus diuji pada lingkungan siaran langsung.
