PROJECT 02 / DETAIL PROYEK
Prototipe

RemoteNotificationSystem

Prototipe sistem untuk menerima dan mengelola event notifikasi dari perangkat Android melalui server, lalu menampilkannya pada panel komputer.

PythonFastAPISQLiteAndroidKotlinTailscale
01 / LATAR BELAKANG

Masalah yang ingin diselesaikan.

Notifikasi dari perangkat yang berbeda perlu dikumpulkan dan diteruskan secara terstruktur. Proyek ini dibuat untuk mempelajari alur komunikasi perangkat Android, API, penyimpanan data, dan panel pemantauan.

02 / FITUR & RUANG LINGKUP

Yang dibangun.

  • Backend server menggunakan FastAPI.
  • Penyimpanan event menggunakan SQLite.
  • Panel kontrol PC berbasis desktop.
  • Aplikasi Android target untuk membaca notifikasi melalui akses notifikasi Android.
  • Pengujian pengiriman event, deteksi duplikasi, dan skenario perangkat offline.
03 / TEKNOLOGI

Tools & teknologi.

PythonFastAPISQLiteAndroidKotlinTailscale
04 / PROSES BELAJAR

Pengalaman teknis.

Merancang alur client-server, endpoint API, penyimpanan event, serta pengujian konektivitas perangkat melalui jaringan privat.

Catatan status: Status saat ini prototipe. Pengujian dilakukan pada satu perangkat target dan fitur lanjutan masih dikembangkan.
