PORTOFOLIO HARIS NAUFAL
======================

Isi:
- index.html        halaman utama website
- assets/style.css  tampilan dan desain responsif
- assets/script.js  menu mobile dan tahun otomatis

SEBELUM DIPUBLIKASIKAN:
1. Buka index.html dan cari EMAIL_KAMU_DI_SINI.
2. Ganti dengan alamat email aktif kamu.
3. Periksa kembali nama, deskripsi, dan status proyek.
4. Upload seluruh isi folder ini ke repository GitHub.
5. Aktifkan GitHub Pages dari Settings > Pages > Deploy from a branch > main > / (root).
