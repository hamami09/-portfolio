PORTOFOLIO HAMAMI
================

Isi website:
- index.html: halaman utama
- projects/: empat halaman detail proyek
- assets/style.css: desain utama
- assets/project-detail.css: desain halaman detail proyek
- assets/script.js: navigasi mobile dan tahun otomatis

PUBLIKASI / PEMBARUAN GITHUB PAGES
1. Ekstrak ZIP ini di komputer.
2. Unggah seluruh ISI folder ke root repository GitHub (bukan file ZIP).
3. Pilih Replace jika diminta mengganti file lama, lalu Commit changes.
4. Pastikan folder assets dan projects ikut terunggah bersama index.html.
5. GitHub Pages akan memperbarui website setelah proses deployment selesai.

Catatan: deskripsi proyek disusun berdasarkan ruang lingkup dan status pengembangan yang diketahui. Halaman detail tidak mengklaim bahwa semua fitur sudah selesai. Ilustrasi pada halaman utama adalah mockup CSS, bukan screenshot aplikasi sebenarnya.
